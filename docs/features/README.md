# Feature Specifications

Create one accepted specification per implementation slice using `templates/FEATURE-SPEC.md`.

Naming convention:

```text
<backlog-id>-<short-kebab-title>.md
```

Examples:

```text
FND-001-005-foundation-bootstrap.md
ACC-004-005-phone-verification.md
LST-006-autos-vertical.md
```

A specification is ready for implementation only when its status, owner, acceptance criteria, non-goals, domain transitions, authorization matrix, data changes, failure behavior, tests, observability, rollout, and unresolved decisions are explicit.
